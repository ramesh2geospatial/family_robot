## Summary
The PWA companion webapp device command POST endpoint dispatches appliance toggles directly to the home adapter without verifying user roles.

## Spec reference
- Requirement: REQ-002
- Spec basis: docs/specifications.md:330-335
- Behavioral contract quote: "Role-based ACL enforced centrally; every privileged action is logged to a tamper-evident audit log."

## The code
At [`packages/core/webapp/app.py:157-177`](file:///d:/GeoNagrik/Dev/git/family_robots/packages/core/webapp/app.py#L157-L177), the POST route `/api/device/command` executes switch and dimmer commands directly without calling `s.acl.check_permission()` or `s.acl.check_device()`.

## Observable consequence
Any local network HTTP client can make a raw POST request to `/api/device/command` to activate or deactivate mains power control devices (geyser, pump, AC) without being authenticated as a parent or adult.

## The fix
```diff
--- a/packages/core/webapp/app.py
+++ b/packages/core/webapp/app.py
@@ -159,2 +159,5 @@
     s = get_state()
+    acl_res = s.acl.check_device(active_user, cmd.device_id)
+    if not acl_res.allowed:
+        raise HTTPException(status_code=403, detail=acl_res.reason)
```
