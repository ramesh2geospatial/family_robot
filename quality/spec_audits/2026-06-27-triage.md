# Spec Audit Triage Synthesis

## Summary
The spec audit confirms major security and safety gaps in the current Phase 1 implementation.

## Triage Actions
- **ACL Bypass in Main Loop**: Enforce user identification and ACL validation checks.
- **ACL Bypass in Webapp Companion**: Require role checks on all endpoint requests.
- **Fail-Open Policy**: Modify `check_permission` in `acl.py` to fail closed.
- **UPS Pi Monitor**: Check charging state to prevent Safe-Shutdown boot-looping.
