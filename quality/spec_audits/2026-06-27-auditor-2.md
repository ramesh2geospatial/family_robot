# Spec Audit Report — Auditor 2 (Access Control Layer)

## ACL & Security Review
- **Policy**: Role-based ACL must be enforced centrally on all privileged commands.
- **Audit Findings**:
  - The voice main loop is completely bypassing the `ACL` check.
  - The companion PWA backend route `/api/device/command` does not call any `ACL` validation.
  - The ACL implementation itself fails open for unrecognized permissions.
- **Verdict**: FAIL.
